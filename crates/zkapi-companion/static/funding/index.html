Fund or withdraw from the terminal

For a new wallet, stop this client, then restart it with zkapi client --fund-with-cast and follow the prompts. Keep the same deployment and state-directory options you use for this client.

To withdraw an existing private balance, run zkapi withdraw --destination 0xYourPayoutAddress with the matching deployment. Withdrawal settles the active key before preparing the payout.

This page does not connect to your wallet or initiate transactions.
